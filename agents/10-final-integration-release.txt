---------------------------

Do not mark the project commercially ready without those reviews.

Acceptance criteria
-------------------
- Fresh clone -> documented local fixture-mode MVP works.
- All root checks pass.
- Empty DB migration + seed works.
- Fixture end-to-end scenario passes.
- Web profile and comparison render from persisted data.
- Admin model version can be validated and activated.
- Addon export and Lua lookup work.
- Docker full stack passes health checks.
- CI configuration validates.
- Production deployment dry run/checklist is complete.
- Live smoke is optional and bounded.
- Known limitations are explicit.
- `doc/agents/10-final-integration.md` follows the handoff template.

Do not
------
- Hide failed acceptance criteria.
- Relax tests merely to produce green status.
- perform bulk provider calls.
- deploy publicly without explicit approval.
- claim scientifically validated scoring.
