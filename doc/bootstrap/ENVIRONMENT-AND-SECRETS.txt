M+ TRUST FACTOR — ENVIRONMENT, CONFIGURATION, AND SECRETS
========================================================

1. General rules
----------------
- Commit `.env.example`, never `.env`.
- Validate all environment variables at process startup.
- Fail fast for required production secrets.
- In tests, use explicit fixture/mock mode.
- No provider secret may ever be sent to the browser.
- Log secret names, never secret values.
- Separate development, test, staging, and production values.

2. Expected variables
---------------------
Application:
- NODE_ENV
- APP_ENV
- APP_VERSION
- API_HOST
- API_PORT
- WEB_ORIGIN
- PUBLIC_BASE_URL
- LOG_LEVEL
- TZ=UTC

Database/queue:
- DATABASE_URL
- REDIS_URL
- RAW_ARTIFACTS_DIR
- RAW_ARTIFACT_RETENTION_DAYS

Blizzard:
- BLIZZARD_CLIENT_ID
- BLIZZARD_CLIENT_SECRET
- BLIZZARD_DEFAULT_REGION=eu
- BLIZZARD_DEFAULT_LOCALE=en_GB
- BLIZZARD_REQUEST_CONCURRENCY
- BLIZZARD_CHARACTER_TTL_SECONDS

Warcraft Logs:
- WCL_CLIENT_ID
- WCL_CLIENT_SECRET
- WCL_PUBLIC_GRAPHQL_URL=https://www.warcraftlogs.com/api/v2/client
- WCL_TOKEN_URL=https://www.warcraftlogs.com/oauth/token
- WCL_RATE_WARN_PERCENT=70
- WCL_RATE_DEFER_PERCENT=80
- WCL_RATE_STOP_PERCENT=90
- WCL_CHARACTER_TTL_SECONDS

Raider.IO:
- RAIDERIO_BASE_URL=https://raider.io
- RAIDERIO_APP_KEY or auth fields only if the registered-app contract requires them
- RAIDERIO_SOFT_RPM=60
- RAIDERIO_REQUEST_CONCURRENCY=2
- RAIDERIO_CHARACTER_TTL_SECONDS=43200

Scoring:
- ACTIVE_SCORE_MODEL_KEY=default
- ACTIVE_SCORE_MODEL_VERSION=1
- MANUAL_REFRESH_COOLDOWN_SECONDS=900

Admin/auth:
- ADMIN_API_KEY for local MVP only, or documented replacement
- SESSION_SECRET
- COOKIE_DOMAIN
- TRUST_PROXY

Production/deployment:
- DOMAIN
- ACME_EMAIL
- GHCR_OWNER
- IMAGE_TAG
- POSTGRES_DB
- POSTGRES_USER
- POSTGRES_PASSWORD
- BACKUP_DIR
- BACKUP_RETENTION_DAYS

3. Local development
--------------------
`docker compose up -d postgres redis`
Then:
- install dependencies
- apply migrations
- seed
- run api, worker, and web in watch mode

The repository must offer one documented command for a full local boot, for example:
- `pnpm dev:infra`
- `pnpm db:migrate`
- `pnpm db:seed`
- `pnpm dev`

4. Fixture mode
---------------
Provide:
- `PROVIDER_MODE=fixture|live`
- Live mode requires credentials.
- Fixture mode is the default for automated tests.
- Fixtures must be sanitized and checked into `tools/fixtures/`.
- Do not make CI depend on external APIs.

5. Secret rotation and production
---------------------------------
- Deployment documentation must explain how to rotate provider credentials.
- Provider tokens are cached only in memory/Redis with TTL, not permanently stored.
- GitHub Actions uses repository/environment secrets.
- VPS receives only runtime secrets required by the selected services.
- Avoid broad SSH keys; use a dedicated deploy user.
