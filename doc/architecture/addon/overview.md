# WoW addon architecture overview

## Purpose

The MPlusTrust Retail addon surfaces a character's **overall Trust Factor grade** in the Group Finder when safe, with a richer **tooltip** (score, confidence, freshness, public red flags). It consumes **static Lua datasets** generated by `tools/addon-exporter` and performs **no HTTP requests**.

## Components

| Layer | Path | Responsibility |
|-------|------|----------------|
| Exporter | `tools/addon-exporter/` | Filter eligible snapshots, partition shards, emit Lua + metadata, package ZIP |
| Dataset | `addon/MPlusTrust/Data/` | Generated `meta.lua`, `shards/**`, `test_vectors.lua` |
| Runtime | `addon/MPlusTrust/*.lua` | Lookup, settings, slash commands, tooltip, LFG adapter |
| LFG UI | `addon/MPlusTrust/lfg/` | Safe `hooksecurefunc` integration, experimental row grade |

## Data flow

```text
Fixture / future DB snapshots
        │
        ▼
  addon-exporter (Node)
        │
        ├── eligibility filter
        ├── shard routing (region/realm/first-char)
        ├── compact record encoding
        └── checksum + meta
        │
        ▼
  addon/MPlusTrust/Data/*.lua
        │
        ▼
  WoW client lookup (MPT_SHARDS registry)
        │
        ├── tooltip on applicant hover
        └── optional row FontString (experimental)
```

## Lookup key

Canonical key: `{REGION}:{realmSlug}:{normalizedName}`

Normalization matches `@mplus/domain` (`NFKC`, lower-case realm/name, upper-case region). Shared vectors live in `tools/addon-exporter/src/constants.ts` and `Data/test_vectors.lua`.

## Safety principles

- No network I/O from Lua.
- No protected attribute mutation or click bindings on LFG secure frames.
- `hooksecurefunc` only on documented Blizzard update functions.
- Row grade disabled by default; tooltip is the primary integration.
- Dataset exposes summary fields only (no dimensions, no admin/premium data).
