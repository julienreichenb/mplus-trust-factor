# Export and packaging

## Exporter CLI

Package: `@mplus/addon-exporter`

| Command | Script | Description |
|---------|--------|-------------|
| Export | `pnpm --filter @mplus/addon-exporter export` | Write `addon/MPlusTrust/Data/**`, refresh `.toc` |
| Benchmark | `pnpm --filter @mplus/addon-exporter benchmark` | Synthetic 10k/100k metrics → `dist/benchmark-report.json` |
| Package | `pnpm --filter @mplus/addon-exporter package` | Export + ZIP → `dist/MPlusTrust-{version}.zip` |
| Lua check | `pnpm --filter @mplus/addon-exporter lua:check` | Parse all addon `.lua` files |
| Tests | `pnpm --filter @mplus/addon-exporter test` | Vitest suite |

Input (MVP): `tools/addon-exporter/fixtures/score-snapshots.json`

Future: worker `generate-addon-export` job reads persisted `ScoreSnapshot` rows (Agent 5) using the same exporter library.

## TOC management

The exporter replaces the block between:

```text
## Data files (generated by addon-exporter)
...
## End generated data files
```

Interface version is currently pinned to `110000` in the TOC; Agent 8 may resolve this at release time.

## Release ZIP

`package` creates `tools/addon-exporter/dist/MPlusTrust-0.1.0.zip` with the `MPlusTrust/` folder at archive root (CurseForge/Wago compatible layout).

**Publishing:** No automated CurseForge/Wago upload is configured. Manual upload steps:

1. Run `pnpm --filter @mplus/addon-exporter package`
2. Upload ZIP to the chosen platform
3. Ensure `X-Website` TOC field points to the public profile base URL

## GitHub Actions contract (Agent 8)

Suggested workflow steps:

```yaml
- run: pnpm --filter @mplus/addon-exporter test
- run: pnpm --filter @mplus/addon-exporter export
- run: pnpm --filter @mplus/addon-exporter lua:check
- run: pnpm --filter @mplus/addon-exporter package
- uses: actions/upload-artifact@v4
  with:
    name: MPlusTrust-addon
    path: tools/addon-exporter/dist/MPlusTrust-*.zip
```
