# Agent 7 — WoW Addon and Static Exporter Plan

## Self-review (pre-implementation)

| Area | Decision | Risk / mitigation |
|------|----------|-------------------|
| Data transport | Static Lua shards generated by Node exporter from fixture snapshots | No HTTP in Lua; exporter never calls external APIs |
| Lookup key | `region:realmSlug:normalizedName` via shared `@mplus/domain` normalization | Shared test vectors in exporter + Lua tests |
| Partitioning | `shards/{region}/{realmSlug}/{bucket}.lua` where bucket = first char of name (a–z, 0–9, `_`) | ~36 buckets/realm; benchmark 10k/100k synthetic |
| Row grade | `hooksecurefunc` on `LFGListApplicationViewer_UpdateApplicantMember` when frame exists | Experimental; disabled by default if taint suspected; tooltip always on |
| Tooltip | `OnEnter`/`OnLeave` on applicant member buttons via secure hook wrapper | Independent of row injection |
| Taint | No `SetAttribute`, no click handlers, no frame creation in combat on protected templates | Adapter no-ops when API missing or `InCombatLockdown()` |
| Settings | `MPlusTrustDB` SavedVariables with versioned defaults | Migration in `settings.lua` |
| Packaging | Exporter writes `addon/MPlusTrust/Data/**`, updates `.toc` interface line | Local `package.mjs` builds ZIP; no CurseForge/Wago publish |

## Current Retail addon interface research (summary)

Retail 11.x Group Finder applicant list:

- Applicant rows are driven by `LFGListApplicationViewer` and per-member `LFGListApplicationViewer_UpdateApplicantMember(button, ...)`.
- Character identity is available on applicant member buttons (`button.name`, `button.realm` or via `C_LFGList.GetApplicantMemberInfo`).
- `hooksecurefunc` on Blizzard global update functions is the standard community pattern; it does not taint callers.
- Directly replacing Blizzard textures or secure attributes on LFG buttons is unsafe.
- `GameTooltip` anchoring on hover is widely used and does not execute protected actions.
- Combat lockdown rarely affects LFG browsing; adapter skips mutations when locked.
- Localization: use global strings where Blizzard provides them; addon strings in `LOCALE_enUS.lua` pattern deferred — MVP uses English constants in `constants.lua`.

Full citations and frame boundaries: `doc/architecture/addon/current-retail-api-research.md`.

## Safe LFG hook strategy

1. **Adapter layer** (`addon/MPlusTrust/lfg/adapter.lua`): probes for `LFGListApplicationViewer_UpdateApplicantMember`, registers `hooksecurefunc` once, exposes `OnApplicantMemberUpdated(button, name, realm)`.
2. **Tooltip module** (`tooltip.lua`): subscribes to adapter; on hover shows grade, score, confidence, freshness, red flags.
3. **Row label module** (`lfg/row_grade.lua`, experimental): adds a non-interactive `FontString` child to member button if template allows; setting `showRowGrade` gates it.
4. **Fallback**: if hook or frame missing, adapter is no-op; `/mpt lookup` and tooltip-on-manual-target still work.

## Taint / protected-frame risks

| Action | Safe? | Notes |
|--------|-------|-------|
| `hooksecurefunc` on LFG update | Yes | Read-only observation + cosmetic FontString |
| `GameTooltip:SetText` on hover | Yes | No click binding |
| Creating frames on LFG secure templates in combat | No | Skip when `InCombatLockdown()` |
| Polling `GetFramesRegisteredForEvent` loop | Avoid | Event/hook driven only |
| HTTP / `C_Curl` / custom sockets | No | Not implemented |

## Tooltip fallback

Tooltip integration is the primary UX path. Row grade is optional and off by default until validated on target build.

## Dataset format and partitioning (v1)

**Metadata** (`Data/meta.lua`):

```lua
MPT_EXPORT_META = {
  formatVersion = 1,
  generatedAt = "2026-07-27T00:00:00.000Z",
  region = "EU",
  season = "season-mvp",
  scoreModelKey = "default",
  scoreModelVersion = 1,
  characterCount = N,
  checksum = "sha256hex",
  shardScheme = "realm_first_char_v1",
}
```

**Shard record** (compact tuple per character):

`[lookupKey] = { score, gradeCode, confidenceBucket, redFlags, freshnessDays, profileKey? }`

- `gradeCode`: S=5, A=4, B=3, C=2, D=1
- `confidenceBucket`: 0–3 from 0–100% thresholds
- `redFlags`: public bitset (6 bits MVP)
- `freshnessDays`: days since `calculatedAt` (capped)

**Canonical lookup key**: `{region}:{realmSlug}:{normalizedName}`

## Eligibility policy (configurable)

Default export filter (fixture mode):

- Region = EU, active season, active score model
- `runCount >= 20`
- `baselineDungeonComplete OR top25Percent`
- `confidence >= minConfidence` (default 0.2)
- `stale === false` (calculated within TTL)
- Website-only ineligible characters excluded unless `includeSearchedIneligible`
