# Battle.net OAuth and IAM Brief

## Core outcomes

- users authenticate with Battle.net;
- owned characters are verified;
- admins use explicit roles and permissions;
- refresh bypasses are auditable;
- the model can later support premium entitlements.

## Privacy rule

Account-to-character links are private by default. Proving ownership of multiple characters does not authorize public alt disclosure.

## Premium separation

Wave 4.3 may introduce generic entitlements, but not Stripe, subscriptions, pricing, checkout or pay-to-win score changes.
