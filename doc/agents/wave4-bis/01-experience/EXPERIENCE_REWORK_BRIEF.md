# Experience Rework Brief

Experience should measure accumulated, relevant Mythic+ exposure. It should not become a second Performance score.

## Candidate concepts

- season participation;
- dungeon breadth;
- key-level breadth;
- multi-season continuity;
- activity recency;
- meaningful historical depth.

## Risks

- raw run count rewards spam;
- highest key duplicates Performance;
- WCL event ingestion is too expensive;
- hidden alt inference breaks transparency;
- provider failure may look like no experience;
- recent rerolls may appear inexperienced even when the account is experienced.

## Wave 4.3 policy

- public score remains character-only;
- account-wide experience is a future authenticated feature;
- the UI must explain what is and is not included.
